## JET2.BIN
- `-RA-` 블록 3,231개(2048 정렬). 머리 16 B = '-RA-' · 0x01010008 · 유닉스 시각 · 0.
- 뒤에 `CMP3` 항목이 이어 붙음(표 없음). CMP3 = 'CMP3' u32 풀린 크기 + **LZSS(Okumura: 고리 4096·0 초기화·r=0xFEE·플래그 LSB 먼저 1=리터럴·복사 2 B 위치 12비트/길이+3)**. 항목 사이 1 B(뜻 모름).
- 머리가 0 인 무압축 블록 41개(0xA08000 등, 0x47000 크기 — 소리?).
- 도구: `tools/cmp3.py`(풀기) · 항목 목록 work/jet2_entries.tsv(블록·위치·항목·크기·첫 4 B).
- ⏳다시 넣기: 압축기(LZSS) 필요. 블록 사이 여유(2048 정렬 + 블록 끝 빈칸)로 크기 늘림 가능한지 미확인. 블록 위치를 찾는 표(ELF? 첫 블록?) 미확인.

## 그림 형식 두 가지
1. **TIM2**(첫 4 B `TIM2`) — 블록 81~ 공항 풍경·간판·기체 텍스처. 7,083장(고유 3,552). `tools/tim2.py` · `tools/dump_tex.py` → work/tex · 시트 work/sheets_tex.
2. **GS 전송 패킷**(첫 u32 `0x600000xx` = DMA 태그 qwc) — **UI 전부**. PACKED A+D(BITBLTBUF·TRXPOS·TRXREG) + IMAGE. 4bpp(0x14)·8bpp(0x13), CLUT 는 같은 항목의 작은 32비트 전송(8×2 / 16×16, 256색은 CSM1 정렬). `tools/gspkt.py` → work/gs(1,295장, 고유 1,258) · 시트 work/sheets_gs(`tools/sheets.py gs`).
